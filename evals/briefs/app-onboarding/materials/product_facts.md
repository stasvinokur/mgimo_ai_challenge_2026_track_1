# «Домашний пульт»: функции и ограничения

## Функции

| Функция | Доступность |
|---|---|
| Баланс, оплата картой, автоплатёж | Все абоненты домашнего интернета |
| Смена имени сети и пароля Wi-Fi | Только для роутеров, выданных «Восход Телеком» (≈ 58% абонентов) |
| Диагностика линии и перезагрузка роутера | Только для роутеров, выданных оператором |
| Заявка мастеру с выбором времени | Все абоненты |
| Управление пакетами ТВ | Нет; в планах на 2027 год |

## Вход

- Сейчас: номер договора + пароль из договора; восстановление пароля — по e-mail, указанному в договоре
  (e-mail есть у ≈ 46% абонентов).
- Тест: вход по SMS-коду на номер телефона из договора — с 28.09.2026 на 10% новых установок Android.
- Номер мобильного телефона указан в договоре у ≈ 93% абонентов.

## Уведомления

- Пуш-уведомления приходят только тем, кто разрешил их в системе.
- Запрос разрешения показывается при первом запуске, до входа.
