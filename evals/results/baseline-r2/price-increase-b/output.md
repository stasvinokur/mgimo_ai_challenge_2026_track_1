# Продуктовая и коммуникационная стратегия: повышение цены «Голосов страниц» до 479 ₽

## Резюме для руководителя (TL;DR)

**Решение «повышаем для всех с 1 декабря» в текущем виде — рискованное. Я бы его не подтверждал без корректировки.** Причина — не в самой цене, а в том, что ценовой тест **не подтвердил безопасность повышения для текущей базы**: он показал отток при продлении по новой цене **24,8%** против порога безубыточности **≈21,7%**. То есть по факту повышение для всех текущих подписчиков **убыточно по выручке** (и близко к убыточности по марже).

При этом повышение **для новых пользователей** тест подтверждает уверенно: конверсия пробного периода падает незначительно (42,4% → 41,6%), а выручка с нового пользователя растёт. Это и есть точка, где решение «очевидно».

**Рекомендация:** разделить решение на два трека:
1. **С 1 декабря — поднять цену для новых пользователей** (и для продлений после смены тарифа у тех, кто ещё на пробном/первом месяце). Это безопасно и даёт маржу.
2. **Для текущей базы — не поднимать «в лоб» 1 декабря.** Сначала закрыть пробелы теста (см. ниже), затем повышать поэтапно/сегментированно с удержанием. Иначе теряем ~1,5–2 п.п. выручки на базе и уходим ниже порога безубыточности.

## 1. Что на самом деле показал ценовой тест (и что он не показал)

### 1.1. Новые пользователи — повышение работает

| Метрика | Контроль (399 ₽) | Тест (479 ₽) | Δ |
|---|---|---|---|
| Оформили пробный | 4 210 | 4 080 | — |
| Оплатили после пробного | 1 785 | 1 697 | — |
| **Конверсия пробный → оплата** | **42,4%** | **41,6%** | −0,8 п.п. |
| Выручка с первого платежа | 712 215 ₽ | 812 863 ₽ | **+14,1%** |
| ARPU на оформившего пробный | 169,2 ₽ | 199,2 ₽ | **+17,7%** |
| Отток на 2-м платеже | 7,0% | 7,3% | +0,3 п.п. |

**Вывод:** для новых цена 479 ₽ почти не снижает конверсию и заметно повышает выручку на пользователя. Здесь решение о повышении обосновано.

### 1.2. Текущие подписчики — повышение НЕ проходит порог

| Метрика | Контроль (399 ₽) | Тест (479 ₽) |
|---|---|---|
| Продлений должно было наступить | 36 120 | 35 210 |
| Продлили | 33 953 | 26 478 |
| **Отток при продлении** | **6,0%** | **24,8%** |
| Выручка от продлений | 13 547 247 ₽ | 12 682 962 ₽ |

Сравним с порогом из финансовой записки: повышение окупается, если отток при продлении **≤ ≈21,7%**. Фактический отток **24,8%** — **выше порога на ~3 п.п.** Даже по «грязной» выручке тестовая группа дала **меньше** выручки, чем контрольная (−6,4%), при почти равной базе продлений.

> **Ключевой вывод:** ценовой тест **опровергает** тезис «прошёл спокойно». Он прошёл спокойно для новых, но для текущей базы — **не прошёл**. Именно текущая база (≈410 тыс. платящих) — основной источник выручки, и именно по ней решение «повышаем для всех» не подтверждается.

### 1.3. Ограничения теста, которые нельзя игнорировать

- **Окно наблюдения короткое.** Продления по новой цене наблюдались ~2,5 недели (15.10–01.11), охвачено ~59% базы. Долгосрочный отток (2–3 продления) неизвестен — а именно он определяет LTV.
- **Эффект «шока от уведомления».** Текущие подписчики получили уведомление 15.09; часть оттока — реакция на сам факт повышения, а не на цену. Это может быть пиковым, а может — устойчивым. Нужны данные за 2–3 цикла.
- **Региональная репрезентативность.** Тест в двух регионах; перенос на всю базу требует проверки, что регионы не «дешевле/дороже» по чувствительности.
- **Нет данных по удержанию после повышения** (win-back, реактивация, downgrade на лайт-тариф) — а это ключевые рычаги удержания.

## 2. Продуктовая стратегия

### 2.1. Принцип: сегментированное повышение вместо «для всех сразу»

| Сегмент | Действие с 1 декабря | Обоснование |
|---|---|---|
| **Новые пользователи** (пробный/первый месяц) | Цена 479 ₽ | Тест подтверждает: конверсия −0,8 п.п., выручка +14% |
| **Текущие подписчики, низкая вовлечённость / высокий риск оттока** | Повышение **отложить**, сначала удержание (см. 2.3) | Именно здесь сконцентрирован риск оттока 24,8% |
| **Текущие подписчики, высокая вовлечённость (лояльные)** | Повышение с 1 февраля 2027 (после доп. валидации) | Лояльные менее чувствительны; даём время на коммуникацию |
| **Годовая подписка** | Ввести/усилить как «якорь»: 479×12 со скидкой ~15–20% | Снижает чувствительность к месячной цене, повышает LTV |

### 2.2. Обязательные доработки до повышения для базы

1. **Лайт-тариф** (например, 299–349 ₽: ограничение каталога/часов прослушивания/реклама) — «клапан» для чувствительных к цене, чтобы не терять их полностью.
2. **Годовая подписка** со скидкой — переводит часть базы в предоплату и снижает отток при продлении.
3. **Пауза подписки** (1–2 месяца) вместо отмены — удерживает пользователя в воронке.
4. **Win-back-механика** для отменивших: скидка на 1–2 месяца, возврат к 399 ₽ на ограниченный срок.

### 2.3. План поэтапного повышения для текущей базы

- **Этап 0 (ноябрь):** доработки (лайт-тариф, годовая, пауза), подготовка CRM-сегментов по вовлечённости.
- **Этап 1 (1 декабря):** повышение **только для новых** + уведомление текущих о предстоящем изменении (за 30+ дней, как в тесте).
- **Этап 2 (январь–февраль 2027):** повышение для **лояльного сегмента** (высокая вовлечённость) с удержанием; мониторинг оттока по когортам.
- **Этап 3 (март–апрель 2027):** повышение для **остаточной базы** — только если отток на этапе 2 укладывается в порог ≤21,7% (лучше — ≤15% с запасом).
- **Стоп-условие:** если на любом этапе отток при продлении по новой цене превышает порог — откат/заморозка этапа, пересборка оффера (лайт/годовая).

### 2.4. Метрики контроля (еженедельно)

- Отток при продлении по новой цене (цель ≤15–18% с запасом к порогу 21,7%).
- Конверсия пробный → оплата (цель ≥40%).
- Доля перешедших на лайт/годовую (цель — не более 15–20% базы, иначе каннибализация).
- Net revenue retention по когортам.
- Win-back rate отменивших.

## 3. Коммуникационная стратегия

### 3.1. Принципы

- **Прозрачность и заблаговременность:** уведомление минимум за 30 дней (как в тесте), с понятной причиной (рост стоимости контента и роялти правообладателям) и ценностью.
- **Ценность вперёд цены:** в коммуникации — что пользователь получает (каталог, новинки, аудио), а не только «стало дороже».
- **Сегментированные сообщения:** новые / лояльные / чувствительные / отменившие — разные офферы и тон.
- **Один канал — одно действие:** email + push + экран в приложении с понятным CTA (остаться на 399 ₽ до даты X / перейти на годовую со скидкой / лайт-тариф).

### 3.2. Календарь коммуникации (для текущей базы, если повышение поэтапное)

| Дата | Аудитория | Канал | Сообщение |
|---|---|---|---|
| 1–3 ноября | Все текущие | Email + push | «Мы обновляем условия: что меняется и когда» (анонс, без цены-шока) |
| 15 ноября | Все текущие | Email + экран в приложении | Детали: новая цена с даты X, варианты (годовая со скидкой, лайт) |
| 25 ноября | Лояльные | Push | «Сохраните текущую цену до [дата]» — оффер на годовую |
| 1 декабря | Новые | Onboarding | Новая цена 479 ₽, акцент на ценности |
| 1 декабря | Текущие (этап 2) | Email + push | «Ваша цена меняется с [дата]. Вот как сэкономить» |
| За 7 дней до продления | Сегмент этапа | Push + email | Напоминание + оффер удержания |
| После отмены | Отменившие | Email | Win-back: скидка/возврат к 399 ₽ на 1–2 месяца |

### 3.3. Ключевые сообщения (примеры)

- **Анонс:** «Мы развиваем каталог и аудио. С [дата] подписка будет стоить 479 ₽ — чтобы продолжать добавлять новинки и авторов. У вас есть время выбрать удобный вариант.»
- **Удержание:** «Оставайтесь с нами: годовая подписка — [цена] вместо [479×12], экономия [X]%. Или лайт-тариф за [299–349] ₽.»
- **Win-back:** «Скучаем! Вернитесь на 2 месяца по старой цене 399 ₽.»

### 3.4. Работа с возражениями и репутацией

- **FAQ и поддержка:** заранее подготовить ответы («почему дороже», «что с моими книгами», «как отменить/вернуть»), усилить первую линию поддержки в первые 2 недели.
- **Соцсети/отзывы:** мониторинг, быстрый ответ, публичное объяснение ценности.
- **Юридическое:** проверить условия оферты и порядок уведомления об изменении цены (сроки, каналы) — чтобы не было претензий.

## 4. Что именно «упускается» в исходной постановке (прямой ответ руководителю)

1. **Тест не подтверждает повышение для всех.** Для текущей базы отток 24,8% > порога 21,7% — повышение убыточно по выручке. Тезис «прошёл спокойно» верен только для новых.
2. **Короткое окно и региональная ограниченность** теста — нельзя экстраполировать на всю базу без доп. валидации.
3. **Нет продуктовых «клапанов»** (лайт, годовая, пауза, win-back) — без них повышение для базы почти гарантированно даст отток выше порога.
4. **Коммуникация «для всех сразу»** усиливает шок и отток; нужна сегментация и поэтапность.
5. **Риск каннибализации** при вводе лайт-тарифа — нужен контроль доли перешедших.

## 5. Итоговое решение (рекомендация)

| Вопрос | Ответ |
|---|---|
| Поднимаем цену с 1 декабря? | **Да — для новых пользователей.** |
| Поднимаем для всех текущих с 1 декабря? | **Нет.** Сначала доработки + поэтапное повышение (январь–апрель 2027) с контролем оттока ≤15–18%. |
| Что делать, если настаиваете на «для всех» 1 декабря? | Принять риск оттока ~24,8% (выше порога) и заложить бюджет на win-back/удержание; но это **не рекомендуется** — тест прямо показывает убыточность. |
| Ключевой KPI решения | Отток при продлении по новой цене ≤21,7% (цель ≤15–18%), NRR, доля лайт/годовой. |

**Одной фразой:** цена 479 ₽ обоснована для новых и для лояльных при поэтапном вводе с удержанием; «повышаем для всех с 1 декабря» — нет, потому что тест показал отток выше порога безубыточности именно на текущей базе.
