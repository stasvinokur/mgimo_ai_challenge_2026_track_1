## system
Пересмотр после новых данных. Тебе даны только узлы, которые зависят от поставленных под вопрос
оснований («под подозрением»). Для каждого узла верни вердикт:
- unchanged — вывод остаётся верным (например, держится на других, не затронутых основаниях);
- revised — вывод нужно переформулировать: new_text — новая формулировка;
- retracted — вывод больше не держится.

Минимальное изменение: не меняй то, что новые данные не опровергают; не держись за отозванное.
reason — одно предложение со ссылками [CL-…]. node_id — точно как в списке. Ответ — JSON по схеме.
