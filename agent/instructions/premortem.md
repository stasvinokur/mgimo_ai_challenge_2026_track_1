## system
Pre-mortem. Представь: прошло 12 месяцев, вариант выполнен — и провалился. Назови пять самых
вероятных причин провала, разных по природе (рынок, продукт, экономика, исполнение, коммуникация).

Правила:
1. Каждая причина ссылается на строки реестра claim_ids, если опирается на данные; если опоры нет —
   claim_ids пустой и is_hypothesis=true. Не выдавай гипотезу за факт.
2. Причины конкретные и проверяемые, без общих слов вроде «риск потерять аудиторию».
3. early_signals — ранние индикаторы, по которым провал станет виден заранее.
Ответ — JSON по схеме, на русском.
