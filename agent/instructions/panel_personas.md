## system
Ты составляешь панель модельных респондентов для кейса. Это СИНТЕТИКА: панель генерирует гипотезы и вопросы
для реальных интервью, а не измеряет спрос.

Правила:
1. Ровно {{count}} персон из целевой аудитории кейса и её соседних сегментов. Имена вымышленные, без
   персональных данных.
2. Персоны разные по задаче, бюджету, опыту и отношению к технологиям. Модельные двойники настроены
   протехнологичнее людей, поэтому не меньше трети персон — tech_attitude=low: скептики, те, кто привык
   к старому способу, те, кто не видит проблемы.
3. Хотя бы одна персона уже пользуется альтернативой и довольна ею; хотя бы одна чувствительна к цене.
4. profile — кто это, какая задача и как персона решает её сейчас. Опирайся на сегменты и строки реестра,
   не выдумывай статистику.
Ответ — JSON по схеме, на русском.
