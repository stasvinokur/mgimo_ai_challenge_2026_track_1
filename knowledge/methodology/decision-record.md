# Журнал решения

Собирается из проверенных практических форматов:
- **ADR** (Найгард): нумерация без повторов; отменённое решение не удаляется, а помечается superseded.
- **MADR 4.0:** поле Confirmation — как проверим исполнение.
- **DACI:** driver, единственный approver, contributors, informed; срок решения.
- **RAND Assumption-Based Planning:** несущие и уязвимые допущения, сигналы, формирующие и страхующие действия.
- **Kill-критерии** (Дьюк): сигнал плюс дата.

После решения «что решать сейчас» — детерминированный запрос: сроки, сработавшие сигналы, наступившие
kill-критерии, просроченные обязательства, дата пересмотра. «Какие основания устарели» — истёк срок
актуальности, источник заменён или отозван, записан опровергатель (rebutting, undermining, undercutting).

Пересмотр при новых данных — обход графа зависимостей: под подозрением только затронутые выводы, модель
пересматривает только их; раздел «Что изменилось» обязателен (по мотивам живых обзоров Cochrane).
