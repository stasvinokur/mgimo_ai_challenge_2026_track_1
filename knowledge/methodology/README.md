# Методика стратега

Методические знания агента — отдельное хранилище (не инструкции и не материалы кейса). Источник правды — эти
файлы; индекс базы знаний пересобирается командой `strategist kb index`. Связи — `[[ссылки]]`.

- [[claims-and-evidence]] — реестр утверждений: типы, опора, надёжность, шкала вероятностей.
- [[decision-framing]] — постановка задачи, посылка запроса, когда спрашивать.
- [[value-of-information]] — план исследования от вопросов, меняющих решение.
- [[options-and-objections]] — обязательные «оставить» и «закрыть», pre-mortem, steelman, панель ролей.
- [[product-strategy]] — JTBD, альтернативы, выбор и осознанные отказы, экономика пользы.
- [[communication-strategy]] — барьеры, ключевое сообщение, роли каналов, сверка обещаний.
- [[experiment-design]] — гипотеза, baseline, MDE, guardrails, kill-критерий, правило решения.
- [[decision-record]] — журнал решения, триггеры пересмотра, обязательства.
- [[synthetic-respondents]] — модельные респонденты на карантине.
- [[interviews]] — гайд интервью по Mom Test и разбор ответов.
