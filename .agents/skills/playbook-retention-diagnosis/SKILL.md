# Диагностика удержания

Падение удержания объясняют четыре группы причин. Исследование должно различить их до выбора варианта.

1. **Измерение.** Изменилось определение метрики, когорты цензурированы (у свежих когорт ещё нет M3), сломан
   трекинг. Проверка: пересчёт метрики кодом по сырым данным, только по завершённым когортам.
2. **Состав аудитории.** Сменились каналы привлечения, сегменты или сезон. Общая цифра падает, хотя внутри
   сегментов всё стабильно (парадокс Симпсона). Проверка: удержание по каналам и сегментам, доля каждого
   канала по когортам.
3. **Продукт.** Пользователи не доходят до ценности: застревают на ключевом шаге, функция не работает на части
   устройств. Проверка: воронка первого опыта по платформам, причины отключения, обращения в поддержку.
4. **Цена и альтернативы.** Конкурент или бесплатная альтернатива, неожиданные списания. Проверка: причины
   ухода с поведенческими полями (подключал ли пользователь продукт вообще), динамика жалоб на оплату.

Порядок: сначала измерение и состав, потом продукт и цена. Заявленные причины ухода сверяйте с поведением
тех же пользователей.

Типичные варианты: исправить измерение и наблюдать; доработать ключевой шаг для проблемного сегмента;
сменить каналы или аудиторию; изменить цену или пакет; заморозить направление.
