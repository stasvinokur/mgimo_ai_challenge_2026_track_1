# Что изменилось после новых данных

*Раздел отчёта агента по демо-кейсу «Скворечник» без правок. Коды вида CL-007 — строки реестра утверждений: у каждой есть источник, они ведут в [полный отчёт](отчёт-целиком.md).*

## Что изменилось

**2 новых источника → 16 новых строк реестра → 4 оснований под вопросом → 17 выводов пересмотрено, 82 узлов не затронуто; решение DEC-0001 открыто заново**

**Основания под вопросом:**
- <a id="CL-040"></a>**[CL-040](отчёт-целиком.md#CL-040)** Снижение удержания вызвано исключительно сложностью онбординга на iPhone. — *гипотеза*, опора: частично, надёжность: очень низкая
- <a id="CL-041"></a>**[CL-041](отчёт-целиком.md#CL-041)** Основной причиной оттока пользователей является высокая цена подписки (199 ₽). — *гипотеза*, опора: подтверждено, надёжность: очень низкая
- <a id="CL-043"></a>**[CL-043](отчёт-целиком.md#CL-043)** Отток пользователей вызван негативным опытом неожиданных списаний при автоподключении по тарифу «Семейный». — *гипотеза*, опора: частично, надёжность: очень низкая
- <a id="CL-060"></a>**[CL-060](отчёт-целиком.md#CL-060)** Точечный фикс можно внедрить и измерить в пределах квартала без роста бюджета и штата — *допущение*, опора: не проверено, надёжность: низкая
